# Open Racetrack DB — bundled data notice

`index.json` in this folder is an **unmodified** copy of `data/index.json` from
[Open Racetrack DB](https://github.com/markthebault/open-racetrack-db) at commit
`03dac92c77d7b7dbc4e892650557c23068ac3ec9`.

Layout traces (`*.geojson`) are not bundled. The app downloads them on demand from the
same pinned commit and caches them under `%AppData%/AcEvoFfbTuner/TrackData/ortdb/`.
