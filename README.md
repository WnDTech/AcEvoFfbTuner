# FFB Tuner

**FFB Tuner** (formerly *AC Evo FFB Tuner*) is free force-feedback tuning software for Assetto Corsa EVO,
Le Mans Ultimate, RaceRoom, Assetto Corsa and ACC — and is becoming part of **WND SimSuite**.

## Download

- **Latest release:** see [Releases](https://github.com/WnDTech/AcEvoFfbTuner/releases/latest)
- **Website:** [ffbtuner.wndtech.tips](https://ffbtuner.wndtech.tips/)

Installed copies update themselves automatically from this page's releases.

## Source code

FFB Tuner is now closed-source freeware. Development continues privately; this repository only hosts releases.

Versions released up to November 2026 were published under the GNU General Public License v2.0 and remain
available under that licence. The Logitech TrueForce helper (**WndTrueForceBridge**) remains free software
under GPL-2.0 — its source is available on request.
